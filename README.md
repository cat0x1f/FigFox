# FigFox

受 [这个项目](https://github.com/omacom/omarchy-site-crt) 与童年时 [电视机的屏保](https://boingboing.net/2025/10/27/old-teac-tube-tv-has-strange-retrogame-style-screen-saver.html) 做出来的主页。

## 本地开发

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产出 dist/
npm run preview  # 预览构建结果
```
